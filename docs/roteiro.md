# Roteiro

Uma etapa por vez. Cada etapa termina com um commit no GitHub e algo que dá para testar no navegador.
Não precisa fazer toda a mobília de uma vez: cada cômodo ganha seus objetos na etapa em que é usado.

| # | Etapa | O que fica pronto | Estado |
| --- | --- | --- | --- |
| 0 | Base | Menu, configurações, créditos, carregamento, pausa, save, gerente de música, visual PS1, conjunto de luzes, salão em blocos | **pronto** |
| 1 | Andar e câmera | Agente (cápsula) andando, correndo, agachando, esquivando; câmera por cima do ombro com braço-mola; colisão com as paredes | próximo |
| 2 | Casa em blocos | Térreo e andar de cima em blocos na escala certa, portas, escadas, checkpoints | |
| 3 | Espectral | Modelo do laboratório em psx, IA (rodear, aviso, bote, tonto), círculo de batalha, mirar e atirar, captura, música de caça | |
| 4 | Glutão | Núcleo e dano reduzido, almas, cuspir, devorar, explosão, manivela | |
| 5 | Buraco e andaime | Guincho, andaime descendo, porta escondida | |
| 6 | Cena e ronda da Mãe | Cena do patamar, esconderijos em primeira pessoa, ronda, perseguição | |
| 7 | Luta no berçário | Barreira, Luto, as 4 fases, berço, captura | |
| 8 | Interface e música | HUD de verdade, detector, música em todos os pontos | |
| 9 | Acabamento | Mobília, texturas finais, modelo do agente, sons, ajuste dos números | |
